# TetOS

Small 32-bit protected mode OS written in C and Assembly, originally for a school project.

Dependencies:
  NASM, CLang

Why almost everything is in one commit, is because I despise version control.

Compiling:
```bash
./compile.sh
./create.sh
```

Running:
```bash
./launcher.sh
```

Compiling and Running:
```bash
./all.sh
```
